🌍 Pilah Sampah Yuk! - Media Belajar Interaktif SD
Aplikasi web interaktif berbentuk game edukasi untuk membantu siswa Sekolah Dasar (SD) belajar memilah sampah ke dalam tiga kategori utama: Organik, Anorganik, dan B3 (Bahan Berbahaya dan Beracun).

✨ Fitur Unggulan
🎮 Sistem Level Progresif:

Level 1: Fokus pada pemilahan sampah dasar (Organik & Anorganik).

Level 2: Tantangan meningkat dengan munculnya sampah kategori B3.

🌓 Mode Gelap/Terang (Dark Mode): Desain visual dinamis dengan pola playful yang disukai anak-anak.

🎲 Shuffle System: Urutan kartu sampah akan diacak secara otomatis setiap kali level dimulai agar tantangan selalu baru.

💡 Fakta Edukasi: Menampilkan fakta unik tentang sampah setiap kali pemain berhasil memilah dengan benar.

🔊 Feedback Audio: Respon suara instan untuk aksi "Benar" dan "Salah".

🔄 Smart Game Reset: Tombol "Main Lagi" mereset game tanpa me-reload halaman, sehingga status Dark Mode tetap terjaga.

🛠️ Prasyarat Teknis
Sebelum menjalankan proyek ini, pastikan perangkat Anda sudah terinstal:

Node.js (Versi 18 atau yang lebih baru)

npm (Node Package Manager)

🚀 Cara Menjalankan Aplikasi
Persiapan Folder:
Masuk ke direktori proyek melalui Terminal atau Command Prompt.

Instalasi Dependencies:
Jalankan perintah berikut:
npm install

Menjalankan Game:
Gunakan perintah berikut untuk menjalankan server lokal:
npm run dev

Buka browser dan akses alamat yang muncul (biasanya http://localhost:5173).

📁 Struktur Penting
src/data/trashData.js: Berisi database item sampah, ikon, dan fakta unik.

src/components/: Berisi logika utama permainan (GameBoard, Draggable, Droppable).

public/: WAJIB menempatkan file success.mp3 dan wrong.mp3 di sini agar fitur suara aktif.

📝 Catatan Pengembangan
Aplikasi ini dirancang sebagai media pembelajaran digital dalam rangka penelitian edukasi lingkungan. Visual dirancang dengan gaya Bold & Boxy untuk menarik minat belajar siswa SD.
